# Image Gallery

This is an Image Gallery website that I developed as part of my **CodeAlpha Frontend Development Internship**.

I wanted to create a simple gallery where users can browse different types of images and easily search and filter them. I also added a fullscreen view and favorites option to make the gallery more interactive.

## About the Project

The website contains images from different categories such as Nature, City, Space, Animals, and Travel.

Users can search for a particular image, select a category, open an image in fullscreen mode, and add their favorite images to a separate favorites section.

I focused mainly on creating a clean, colorful, responsive, and easy-to-use interface.

## Features

- View images in a responsive gallery
- Search images by title or category
- Filter images based on categories
- Add and remove images from Favorites
- Open images in fullscreen view
- Previous and Next buttons in the fullscreen view
- Close the fullscreen image easily
- Responsive design for different screen sizes
- Hover effects on gallery images
- Colorful gradient background
- Animated background particles
- Simple and user-friendly interface

## Categories
